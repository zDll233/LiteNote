# 更新日志

轻签 LiteNote 的版本变更记录。版本号与 `src-tauri/tauri.conf.json` 保持一致，安装包见 [GitHub Releases](https://github.com/zDll233/LiteNote/releases)。

## [1.5.1] - 2026-11-10

### 修复

- **编辑待办时的可视区域**：编辑框原本固定两行、超出部分在框内滚动，现在编辑区随内容完全展开，不再出现内部滚动条
- **编辑态字号**：进入编辑时字号由 14px 变为 16px 导致文字重新折行，现与展示态完全一致（14px / 1.375 行高）
- **光标可见性**：列表可视区较矮时，长待办进入编辑后自动滚动到光标所在位置

### 构建

- 新增 GitHub Actions 发布流水线：推送 `v*` 形式的 tag 自动构建 Windows x64 NSIS 安装包并创建 Release

## [1.5.0] - 2026-10-20

### 新增

- **自定义背景图片**：可选择本地图片作为小部件背景，图片落盘存储，避免大图写入设置字段
- **已完成视图**：按完成时间分组（今天 / 近 3 天 / 近 7 天 / 近 30 天 / 更早），分组可折叠
- **备注与进度**：待办支持备注文本与完成进度（0–100%），通过行内气泡卡片编辑，列表中直接展示进度
- **自然语言日期**：输入待办时自动解析「明天」「下周三 15:00」等日期表达
- **提醒提前量可调**：截止提醒的提前时间支持自定义（默认 15 分钟）
- **循环多选日期**：每周 / 每月循环支持多选星期几、多选几号

### 改进

- 主题配色改用 CSS 变量统一管理，替换硬编码颜色，便于后续换肤
- 支持锁定窗口，锁定后禁止拖动整个悬浮窗口
- WebDAV 同步改为「本地覆盖云端」策略，并修复已删除待办被云端复活的问题

### 修复

- 修复窗口离屏后不可见
- 修复启动时窗口被隐藏的问题

## [1.4.0] - 2026-08-08

### 新增

- **快捷键自定义**：设置页新增「快捷键」页，显示 / 隐藏窗口、专注模式切换、窗口置顶三条快捷键均可自定义，支持清空与冲突检测
- **复制待办**：右键菜单「复制到…」把待办复制到指定日期，生成独立新条目，原条目不受影响
- **WebDAV 云同步**：内置坚果云配置，支持测试连接、立即同步、从云端恢复；密码本地加密存储，双向合并同步

### 改进

- 同步流程增强安全性与稳定性
- 待办删除交互优化

## [1.3.0] - 2026-06-18

### 新增

- **专注模式 / 完整模式**：一键在精简待办列表与完整面板之间切换，专注模式设有最小高度
- **弹窗提醒**：在系统通知之外新增钉钉式弹窗提醒，两种模式可选
- **置顶快捷键与托盘菜单**：窗口置顶支持快捷键，托盘右键菜单可设置
- **导出 TXT**：可将待办导出为文本文件
- **记住窗口大小与位置**：重启后恢复上次的窗口尺寸与位置
- **面板透明度**：透明度设置作用于背景层，并优化背景样式

### 改进

- 任务栏不显示（skipTaskbar），小部件常驻桌面更清爽
- 图标组件化，替换图钉图标
- 设置页布局与滚动条优化

### 修复

- 修复重复提醒
- 修复 macOS 切换模式后窗口持续变大的问题

## [1.2.0] - 2026-06-05

### 新增

- **周日历**：顶部周一到周日日历条，支持 `<` `>` 切换周，点击日期筛选当日待办
  - 红点标记：该日期有待办
  - 橙色点标记：该日期有逾期未完成的待办
  - 选中日期后添加待办，自动设置截止时间为当天 23:59
- **拖拽分配日期**：拖拽待办到日历上的日期格子，自动设置截止时间
  - 循环待办不允许拖拽到日历
  - 仅在指针进入日历区域时触发，列表内拖拽仍为排序
- **多主题切换**：内置毛玻璃、深色、浅色三套主题
  - CSS 变量驱动，一键切换即时生效
  - 主题选择持久化存储，跨启动保留
- **内嵌设置弹窗**：设置页面从独立窗口改为模态弹窗
  - Switch 滑动开关替换 Checkbox
  - 自定义下拉选择替换原生 `<select>`
  - 透明度滑块优化，轨道/滑块清晰可见
- **关于弹窗**：帮助页面改为内嵌弹窗，含 B 站链接、QQ 群、微信（点击复制）

### 改进

- 主题色系统重构为 CSS 变量，三套主题共用一套变量名
- 周日历配色全线改为 CSS 变量，修复 Tailwind v4 下部分颜色失效问题
- 时钟区移至周日历上方
- 模态弹窗使用 Portal 渲染到 `document.body`，不受主面板透明度影响

### 修复

- 新增待办截止时间从 00:00:00 修正为 23:59:59，避免当日显示“逾期”
- Windows NSIS 安装包加入 WebView2 引导安装
- 循环待办图标 `pointer-events-none`，修复拖拽被图标拦截的问题

### 移除

- 独立设置窗口（`settings.html`、`SettingsForm`、`openSettingsWindow`）
- 独立帮助窗口（`help.html`、`openHelpWindow`）
- 相关未使用的 i18n 文案（`helpText`、`helpOpenFailed`）

## [1.1.0] - 2026-05-29

### 新增

- **循环待办**：支持每天/每周/每月重复提醒，可自定义具体时间和目标日
  - 每天：选择具体几点提醒
  - 每周：选择星期几 + 几点提醒
  - 每月：选择几号 + 几点提醒
  - 到达设定时间后自动进入下一轮，无需手动操作
  - 循环待办不可标记完成，只能删除
- **拖拽排序**：长按待办条目拖动即可调整顺序，5px 移动阈值避免误触
- **标题栏版本号**：左上角动态显示当前版本号

## [1.0.0] - 2026-05-23

### 功能

- 本地待办：SQLite 存储，支持新增/编辑/删除/完成
- 置顶、重要程度颜色标记
- 截止时间：快速设置（今天/明天/本周末）和自定义日期时间
- 截止提醒：到期前 15 分钟系统通知（Rust 后端 + 前端双保险轮询）
- 时钟与农历：可选显示（默认折叠）
- 无边框透明面板，毛玻璃效果，透明度可调
- 窗口置顶、关闭隐藏到系统托盘
- 全局快捷键 `Ctrl+Shift+L` / `⌘+Shift+L` 唤出/隐藏
- 独立设置页：透明度、时钟折叠、语言（中/英/跟随系统）、开机启动
- 跨平台：Windows（NSIS + 便携版）、macOS（.app / .dmg）
